# Test and lint dependencies for the Dockhand integration.
#
# The unittest suite itself uses only stdlib + ha_stubs and requires no
# third-party packages. Ruff is the only external dependency, used for
# linting the integration source.
#
# To run everything (lint + tests):
#   python3 tests/run_tests.py          # direct; warns and skips lint if ruff missing
#   bash scripts/run_tests.sh           # via venv; installs ruff automatically
#
# To install manually:
#   pip install ruff
#
# Optional: install pyyaml for workflow static analysis tests
#   pip install pyyaml
# Without pyyaml the workflow tests are automatically skipped.
